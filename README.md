# Guillermo e Ingrit

Invitación digital de boda — Quinta Las Palmeras, 19 de diciembre de 2026.

## Desarrollo

```bash
npm install
npm run dev
```

## Variables de entorno

Copiá `.env.example` y completá:

- `NEXT_PUBLIC_SITE_URL` — URL pública (WhatsApp preview)
- `GOOGLE_SCRIPT_URL` — URL `/exec` de Apps Script

## Apps Script

El archivo está en `apps-script/Code.gs`. Pegalo en la Sheet de invitados, implementá como aplicación web y usá la URL `/exec` en Vercel.
